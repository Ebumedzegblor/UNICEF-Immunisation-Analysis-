# Project Background

## Project Title
Exploring Global Immunisation Coverage Using WUENIC Data

## Background
This project uses the WHO and UNICEF Estimates of National Immunization Coverage (WUENIC) dataset to explore immunisation coverage across countries, vaccines, years and target groups.

The project is intended to demonstrate practical SQL skills, including data preparation, data quality assessment, data exploration and analytical querying.

## Project Objectives

1. Understand the structure and contents of the WUENIC dataset.
2. Assess the quality and consistency of the data.
3. Prepare the dataset for reliable SQL analysis.
4. Explore immunisation coverage patterns across countries, vaccines and years.
5. Communicate the analytical process, key findings and data limitations through clear, reproducible documentation.

## Data Source

Dataset: WHO and UNICEF Estimates of National Immunization Coverage (WUENIC).

Dataset version: 2025 revision.

Original format: Excel (.xlsx).

The dataset was obtained from UNICEF's official immunisation data resources.

## Tools Used

- Google Sheets: conversion of the downloaded Excel dataset to CSV.
- SQLiteOnline: importing, querying and exploring the data.
- SQL: data preparation and quality inspection.

## Project Status

Currently in the data preparation and data quality inspection stage.
